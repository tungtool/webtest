## 🚀 Hướng dẫn chạy test nhanh:
1. Giải nén file `.zip` này vào máy của bạn.
2. Mở terminal/CMD tại thư mục vừa giải nén:
   ```bash
   npm install
   npx prisma migrate dev --name init
   npm run dev
   ```
3. Truy cập: `http://localhost:3000` để test toàn bộ tính năng!
